        The collector reads local Claude Code and Codex session logs only for
        your selected project and event period. It extracts a fixed set of
        fields:
      

      
    
        
  • Team name and tool: Claude Code or Codex
    • 
        
  • Input, output, cache-read and cache-write counters
    • 
        
  • Usage timestamp and anonymous IDs to prevent duplicates
    • 
      

      

        Prompts, answers, source code, filenames, usernames and provider
        credentials are never included in reports. Local logs can contain
        sensitive content; filtering happens on your machine.
      

      

        Counts are self-reported from agent logs, not verified billing records.
        Missing provider telemetry cannot be reconstructed. Cache tokens are
        already included in input totals.
      

      

        Collection is opt-in and scoped to one project. Pause it or remove the
        hooks at any time. The organizer controls server retention; the hosting
        provider may see connection metadata such as IP addresses.
